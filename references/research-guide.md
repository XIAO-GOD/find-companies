# Public-source research guide

## Research boundary

Research broadly, then write selectively. The output supports an initial investor visit, not a full diligence conclusion. Separate facts, company claims, analysis, and unknowns throughout.

## Source hierarchy

Prefer sources in this order, while matching the source to the claim:

1. Government, regulator, exchange, court, standards body, public procurement, or official registry records.
2. Patent documents, peer-reviewed papers, conference proceedings, technical standards, product manuals, test reports, and certification databases.
3. The company's website, official account, filings, founder interviews, product releases, and recruiting pages. Treat these as primary evidence of what the company says, not independent proof of performance.
4. Customer or partner announcements that name the company and describe a concrete project.
5. Reputable financial, industry, and technology media with named authors and dates.
6. Databases and aggregators. Use them to locate original evidence; label facts that cannot be traced further.
7. Forums, reposts, social posts, and search snippets. Use only as leads unless independently confirmed.

Do not infer current facts from stale pages without noting the date. Do not treat the number of search results as evidence.

## Search matrix

Search the legal name, brand, aliases, English name, founders, and flagship products. Use combinations from each row.

| Facet | Typical queries and targets |
|---|---|
| Identity | 公司名 官网 / 法定全称 / 总部 / 成立 / 子公司 / English |
| Product | 公司名 产品 / 型号 / 参数 / 手册 / 发布 / 解决方案 |
| Technology | 公司名 技术路线 / 专利 / 论文 / 测试 / 认证 / 标准 / benchmark |
| Team | 公司名 创始人 / 首席科学家 / 核心团队 / 履历 / 采访 |
| Financing | 公司名 融资 / 投资方 / 轮次 / 金额 / 工商变更 |
| Customers | 公司名 客户 / 中标 / 采购 / 验证 / 交付 / 定点 / 合作 |
| Capacity | 公司名 产线 / 扩产 / 基地 / 良率 / 产能 / 招聘 / 售后 |
| Competition | 产品类别 竞品 / 替代路线 / 国际厂商 / 国产化 / 市占率 |
| Risk | 公司名 诉讼 / 处罚 / 召回 / 失信 / 知识产权纠纷 / 延期 |

For search engines that support it, use `site:` queries for official domains, government domains, patent portals, procurement portals, and reputable media. Search the date range relevant to “current” status and note the cutoff.

## Minimum coverage checklist

Attempt each item; mark unavailable items as unknown rather than omitting them silently.

- Exact entity and official web presence
- Product form and target customer
- Customer's current alternative and switching reason
- Technical route and one measurable differentiator
- Prototype, validation, delivery, or scale stage
- One concrete customer or partner journey, if publicly available
- Founders and role coverage relevant to execution
- Disclosed financing history and current round, if any
- Principal competitors and substitute routes
- Intellectual-property, paper, certification, or standards evidence
- Manufacturing, delivery, quality, recruiting, or after-sales signals
- Material contradictions, stale claims, or negative public signals

## Claim discipline

- Cite the underlying page, not a search query URL.
- Prefer at least two independent sources for decisive claims such as “industry first,” “mass production,” “exclusive supplier,” or “leading performance.”
- If only the company makes the claim, use `company_claim` and attribute it directly.
- Use `analysis` only when cited evidence logically supports the inference. State the reasoning in one sentence.
- Use `unverified` for conflicting, snippet-only, anonymous, inaccessible, or undated information.
- Never invent revenue, valuation, market share, customer names, orders, yields, or performance metrics.

## Synthesis heuristics

Use the causal chain:

`technical indicator → stable product → customer validation → procurement reason → repeatable delivery → defensibility → next financing milestone`

For the first visit, identify where the chain is supported, where it breaks, and what evidence would repair it. Select topics and questions from the weakest consequential links rather than using a generic checklist.

When information is sparse, produce a shorter report with stronger unknowns. When information is abundant, compress repeated publicity and retain only decision-relevant evidence.
